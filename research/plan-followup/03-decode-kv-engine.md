## 3. Proposals
(a) Paged per-stage KV (page 16/32, block table per layer range; `O((P+t)×delta)` per step, zero protocol change) + prefix-handle+delta transfer (`{kv_handle,cached_len,delta_len}` in codec meta; orchestrator tracks per-stage `cached_len` filling session hole) + speculation rollback (`truncate_to` broadcast refining clear channel). Stages never exchange KV bytes. Gates: ≥4× tok/s @2k, ≥8× @8k; ≥10× net bytes cut @≥2048; ≥80% prefix-FLOP skip; 200-prompt greedy parity 100% + reject-injection test.
(b) Chunked prefill: `max_extend_tokens` 2048-8192 admission (FreeToken `scheduler/config.py:16`), interleave decode between chunks, per-chunk KV commit. Gates: 8k-prefill peak ≤1.3× 2k steady (`cuda.max_memory_allocated`); TTFT ≤1.5× unbounded; no OOM 32k on 24GB.
(c) Ladder: 1) INT8/FP8 KV+FP16 weights (halve long-ctx mem, +30% tok/s @8k); 2) harden bnb-4bit-NF4 (pin, warn, parity gate; 7B ≤6GB, ≤2% regression); 3) torchao FP8 weights SM90+ (≥1.25× GEMM; train refuses/LoRA-wraps); 4) fused attention + `torch.compile` fixed-shape decode last (≥1.5× step). Order enforced (quant-before-cache traps benchmark wins).
