Kiến trúc cốt lõi

1. Latency-Aware Collaborative Partitioning (LACP)
Thuật toán tự động đo đạc độ trễ mạng, băng thông và năng lực tính toán (TFLOPS) của từng Node trong Cluster để phân chia (Shard) số lượng Layer phù hợp của LLM. Tránh hiện tượng nghẽn cổ chai (Bottleneck) ở các Node yếu.

2. Fault-Tolerant Distributed Pipeline
Cơ chế Pipeline Parallelism sử dụng gRPC với khả năng Retry và Auto-Discovery. Nếu một Node mất kết nối, Cluster sẽ tự động cấu hình lại (Re-partition) các Layer sang các Node còn lại trong vòng vài giây.

3. Parameter-Efficient Fine-Tuning (PEFT/LoRA)
Hỗ trợ huấn luyện tinh chỉnh trực tiếp trên Web UI với kỹ thuật LoRA, tiết kiệm tối đa VRAM, xuất Checkpoint an toàn và tái sử dụng cho Inference.

Mục tiêu dự án

1
Phá vỡ giới hạn Phần cứng — Chạy các Model siêu lớn (70B, 405B) bằng cách gộp VRAM/RAM từ nhiều thiết bị cá nhân/IoT qua mạng nội bộ hoặc Tailscale.
2
Quản trị AI All-in-One — Tích hợp đầy đủ quy trình MLOps: Quản lý Model, Đánh giá (Benchmark), Dataset, Huấn luyện và Triển khai API chuẩn OpenAI.
